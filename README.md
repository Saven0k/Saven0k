## 👋 Привет!

Я **Роман Савенков** — **Frontend Developer / Frontend-разработчик** из Санкт-Петербурга.

Разрабатываю интерфейсы на **React и TypeScript**: каталоги, личные кабинеты и административные панели. Работаю с состоянием приложения, формами, адаптивной вёрсткой и интеграцией с **REST API**.

Уделяю внимание понятным пользовательским сценариям и поддерживаемому коду. Опыт работы с **NestJS и Express** помогает учитывать контракт API и эффективно взаимодействовать с backend-разработчиками.
